# POWER-HOUSE-HOPEProject

Information Management HOPE Project, Sprint 1 to 4 workspace.

This repo contains the files for our HOPE website: the SQL of the database, the backend of the website, and the front end of the website.

## WELCOME!
Here is how we work in this repo.

## GET THE CODE
```
git clone https://github.com/Ras-cymk/POWER-HOUSE-HOPEProject.git
```

## RULES
- `main` is protected. Nobody commits to it directly.
- Make a branch, make your changes, then open a pull request.
- Fill in the PR template and write the task ID (e.g. S1-DEV-02).
- Link your PR to its issue and assign yourself on both the issue and the PR.
- A teammate must approve your PR before it is merged.
- One task = one pull request.

## OTHER INSTRUCTIONS
- Instructions or messages related to the DB or Supabase are in DB_ADMIN_README.md
- Instructions or messages related to the website are in DEV_README.md

## NEED HELP?
GitHub access, branch rules, PR or issue templates: message the Scrum Master.
