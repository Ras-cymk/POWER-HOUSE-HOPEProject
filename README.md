# WELCOME!
Here is how we work in this repo.

## GET THE CODE
```
git clone https://github.com/Ras-cymk/POWER-HOUSE-HOPEProject.git
```

## RULES
- `main` is protected. Nobody commits to it directly.
- Make a branch, make your changes, then open a pull request.
- Fill in the PR template and write the task ID (e.g. S1-DEV-02).
- A teammate must approve your PR before it is merged.
- One task = one pull request.


## Other instructions
- Instructions or messages related to the DB or SupaBase is in DB_ADMIN_README.md
- Instructions or messages related to the Website is in DEV_README.md


## NEED HELP?
GitHub access, branch rules, PR or issue templates: message the Scrum Master.
