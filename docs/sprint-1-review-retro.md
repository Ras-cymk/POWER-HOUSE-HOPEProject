## 2. Retrospective

**What went well**
- Developer and DB Admin finished all 14 of their planned tasks.
- The PR workflow worked: `main` stayed protected, and merged PRs were approved by a teammate.
- All Scrum Master tasks were completed.


**What didn't go well**
- No Tester PRs were merged, and most Tester tasks had no named owner.
- Four UI/UX tasks are in one PR (#35), which breaks our "one task = one PR" rule.
- Board issues were created late, so some PRs were hard to link to a task.


**What to change next sprint**
- Create the board issue for every task at the start of the sprint.
- Assign an owner to every task before the sprint begins.
- Check in more often in Messenger.
